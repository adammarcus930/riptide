# Riptide

Self-contained iOS workout app: generates full-body lifting programs from
effort, days, and muscle selections, then tracks set-by-set logging with
cross-program exercise history.

- **Spec:** docs/superpowers/specs/2026-07-19-riptide-design.md
- **Plan:** docs/superpowers/plans/2026-07-19-riptide.md
- **Build:** `xcodegen generate` then open `Riptide.xcodeproj` (iOS 17+).
- **Core tests:** `cd RiptideCore && swift test`
